The reference on the left is built from [`/api/v1/openapi.json`](https://purps.lol/api/v1/openapi.json), which the site serves from the same source its own pages use. Each endpoint page has a playground you can call directly.

Reads are grouped under **Coins**. Writes are grouped by what you are doing: launching on one of three venues, redirecting a pump.fun coin, managing a coin you launched, and trading. **Transactions** is the Solana relay every Solana write ends with.
