PURPS is a launchpad where a coin's trading fees work for its holders. Fees are claimed automatically and either buy the coin back and burn it, are airdropped to holders, or fund perpetual futures positions whose profits go to holders.

Everything the site does can be done through this API: read any coin's books, launch a coin on purps.lol, pump.fun or Pons (on Robinhood Chain), wire an existing pump.fun coin's fees into a strategy, and steer a coin you own.

This is v2. The old `/api/v1` reads still answer, served by v2 with the same shapes; the old v1 write addresses answer `410` with a pointer here.

## First call

<CodeGroup>

```bash curl
curl "https://purps.lol/api/v2/coins?sort=newest&limit=3"
```

```js JavaScript
const res = await fetch("https://purps.lol/api/v2/coins?sort=newest&limit=3");
const { ok, data } = await res.json();
console.log(data.items.map((c) => `${c.symbol} $${Math.round(c.marketCapUsd)}`));
```

```python Python
import requests

r = requests.get("https://purps.lol/api/v2/coins", params={"sort": "newest", "limit": 3})
for coin in r.json()["data"]["items"]:
    print(coin["symbol"], coin["marketCapUsd"])
```

</CodeGroup>

Every response is `{ "ok": true, "data": … }` or `{ "ok": false, "error": "…" }`. Base URL: `https://purps.lol/api/v2`.

## How it works

<CardGroup cols={2}>
  <Card title="No keys" icon="key-round" href="/guides/signing">
    A launch is one call; the transaction you sign is the proof. The few writes that need a message signature come as prepare, sign, submit.
  </Card>
  <Card title="Non-custodial" icon="shield-check" href="/guides/signing">
    We never hold your key. Transactions are built for your wallet to sign; a launch's throwaway mint key is handed to you as `mintSecret`, and the only signature we ever add is the launchpad's own memo co-sign on a purps.lol create.
  </Card>
  <Card title="Launches finish themselves" icon="rocket" href="/guides/launch-solana">
    Once your launch lands, we see it on chain, mark the coin live and attach the strategy you sent with the build, on every launchpad. A strategy is a preset and the markets: `{ preset: "balanced", markets: ["ETH"] }`.
  </Card>
  <Card title="Frozen shapes" icon="lock">
    Fields may be added to v2. None will be renamed or removed.
  </Card>
</CardGroup>

## What you can do

<CardGroup cols={2}>
  <Card title="Launch on purps.lol" icon="/icons/purps.svg" href="/guides/launch-solana">
    A coin on a Meteora curve, paired with SOL or any listed token, with fees to holders, to you, or into a strategy.
  </Card>
  <Card title="Launch on pump.fun" icon="/icons/pumpfun.svg" href="/guides/launch-pumpfun">
    pump.fun's own curve, with creator fees wired into a strategy from the first trade. One build, two signed transactions, and we register the strategy.
  </Card>
  <Card title="Launch on Pons" icon="/icons/pons.svg" href="/guides/launch-pons">
    An EVM coin on Pons, Robinhood Chain's launchpad, paired with ETH or a listed token. One signed message, the steps to send, and we attach the strategy.
  </Card>
  <Card title="Redirect a pump.fun coin" icon="/icons/pumpfun.svg" href="/guides/redirect">
    Point an existing pump.fun coin's fees at a strategy.
  </Card>
  <Card title="Manage a coin" icon="sliders-horizontal" href="/guides/manage">
    Attach a strategy to a coin launched without one.
  </Card>
  <Card title="Creator authority" icon="shield-check" href="/guides/creator-authority">
    Steer a coin you own: act on a position, change its strategy, hand it on. Every move signed and shown to holders.
  </Card>
</CardGroup>

## For agents

An agent that lands on purps.lol reads [llms.txt](https://purps.lol/llms.txt) first: what PURPS is, every endpoint, and the flows. The full machine-readable spec is at [openapi.json](https://purps.lol/api/v2/openapi.json).
