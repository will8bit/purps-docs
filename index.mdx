PURPS is a launchpad where a coin's trading fees go back to its holders. We claim the fees automatically and either buy the coin back and burn it, airdrop them to holders, or use them as margin for perpetual futures (perps) positions whose profits go to holders.

Everything the site does, you can do from this API: read any coin's books, launch a coin on purps.lol, pump.fun or Pons (Robinhood Chain's launchpad), point an existing pump.fun coin's fees at a strategy, and steer a coin you own.

This is v2. Old `/api/v1` reads still work and return v2 data. Old v1 write addresses return `410` and point here.

## First call

<CodeGroup>

```bash curl
curl "https://purps.lol/api/v2/coins?sort=newest&limit=3"
```

```js JavaScript
const res = await fetch("https://purps.lol/api/v2/coins?sort=newest&limit=3");
const { ok, data } = await res.json();
console.log(data.items.map((c) => `${c.symbol} $${Math.round(c.marketCapUsd)}`));
```

```python Python
import requests

r = requests.get("https://purps.lol/api/v2/coins", params={"sort": "newest", "limit": 3})
for coin in r.json()["data"]["items"]:
    print(coin["symbol"], coin["marketCapUsd"])
```

</CodeGroup>

Every response is `{ "ok": true, "data": … }` or `{ "ok": false, "error": "…" }`. Base URL: `https://purps.lol/api/v2`.

`GET /coins` is the ranked list; add `creator=<wallet>` for one wallet's coins. `GET /launches` is the purps.lol launches, filterable by `status`, `curve`, `quoteMint` or `creator`.

## How it works

<CardGroup cols={2}>
  <Card title="No keys" icon="key-round" href="/guides/signing">
    A launch is one call and the transaction you sign is the proof; the few writes that need a message signature go prepare, sign, submit.
  </Card>
  <Card title="Non-custodial" icon="shield-check" href="/guides/signing">
    You sign every transaction in your own wallet, the launch's throwaway mint key comes back to you as `mintSecret`, and the only signature we add is the launchpad's memo co-sign on a purps.lol create.
  </Card>
  <Card title="No second step" icon="rocket" href="/guides/launch-solana">
    Once your launch lands we see it on chain, mark the coin live and attach the strategy you sent with the build (a preset and the markets: `{ preset: "balanced", markets: ["ETH"] }`), on every launchpad.
  </Card>
  <Card title="Frozen shapes" icon="lock">
    We may add fields to v2; we won't rename or remove any.
  </Card>
</CardGroup>
